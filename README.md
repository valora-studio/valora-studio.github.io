# Сайт Valora

Сайт самой студии: услуги, цены, оферта, оплата и возврат, политика ПДн.
Нужен в первую очередь для подключения ЮKassa — она проверяет сайт
на цены, контакты, ФИО и ИНН, оферту и условия возврата.

Образец по составу страниц — `murzzsite/smarzhak-cpa`. Оформление — фирстиль
Valora S6 (чернила/бумага, Jost, без акцента), а не продающий формат
клиентских лендингов: это лицо самой студии.

## Сборка

Страницы генерируются, руками `*.html` не править — перезапишутся.

```bash
PYTHONIOENCODING=utf-8 python build.py          # → 9 страниц рядом
PYTHONIOENCODING=utf-8 python shot.py           # рендеры 1440 в out/
PYTHONIOENCODING=utf-8 python shot.py 500       # рендеры под телефон
```

Контакты и реквизиты — в словаре `SITE` в начале `build.py`. Пока телефон,
почта или Telegram пустые, `build.py` выходит с кодом 1 и печатает, чего нет.
